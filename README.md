# Oxana - Fearless Soul

Single-page interactive birthday gift site.

## GitHub Pages

This repo is prepared for GitHub Pages without a build step.

1. Push the repo to GitHub.
2. Open the repository on GitHub.
3. Go to `Settings` -> `Pages`.
4. Set:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/docs`
5. Save.

The published site will use `docs/index.html` and the local assets in `docs/`.

## Local Preview

Open:

```text
docs/index.html
```

or the working preview:

```text
outputs/oxana-birthday-site/index.html
```
